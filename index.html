Thesis Project: FairWindSK

C++17 / Qt 6 • Cybersecurity • 2026

A touch-native, open-source and cyber-resilient shell that acts as the onboard runtime for the Signal K open marine data ecosystem, developed within the DYNAMO oceanographic project at Università Parthenope (supervisor: Prof. Raffaele Montella).

The challenge: run one secure graphical application, natively, on five very different operating systems (Linux, macOS, Windows, Android and iOS) inside a hostile environment such as a boat's bridge, where network drops, wet screens and unauthenticated onboard buses are the norm.

My contribution

  • Ported the onboard shell into a cross-platform C++ application built with Qt.
  • Applied secure coding principles and threat modeling to the architecture.
  • Reworked the UI templates and implemented the app's web connections.
  • Built and tested it on Raspberry Pi, desktop, Android and iPad.

Memory safety

Modern C++17 only: RAII and smart pointers, no raw new / delete. Buffer overflows, use-after-free and leaks are prevented by design (zero leaks in a 72-hour stress test).

Hardware root of trust

JWT tokens and credentials are never stored in plain text: they are sealed in Apple Secure Enclave, Android Keystore, Windows DPAPI or Linux Secret Service.

Semantic firewall

Every telemetry value is checked against physical ranges and kinematic gradients (Δv/Δt) to block GNSS spoofing and fake depth injections on NMEA 2000 / CAN buses.

Threat modeling

Attack surface mapped with STRIDE across three trust boundaries and risks prioritized with DREAD, driving the design of each countermeasure.

Network resilience

An asynchronous connection state machine with exponential backoff and "snapshot hydration" reconnects in the background without ever freezing the UI.

Trusted data on screen

Each widget moves through Live → Stale → Missing states, so the helmsman never steers by a frozen GPS position or an outdated depth reading.
